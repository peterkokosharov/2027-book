# Glossary of the Bulgarian reading copy

Rules used: person names are transliterated; meaningful house/object names are translated; invented house names with no meaning are transliterated; house names are quoted („...“) in running text.

## Conventions

- Times written "p.m." in the English are given in the 24-hour form with "ч." (e.g. 9:14 p.m. = 21:14 ч.; 10:42 p.m. = 22:42 ч.; 4:40 and 4:50 in the afternoon = 16:40 ч., 16:50 ч.); no figure was changed.
- Code identifiers (`legacy_flag_2`), software names (Java, Go, Postgres) and the message text "GPU quota in region east-1" stay in Latin.
- Source file names in the closing "Sources" note stay in Latin.
- Quotation marks: „...“ for Bulgarian quotations and names of houses; dashes are en dashes with spaces.
